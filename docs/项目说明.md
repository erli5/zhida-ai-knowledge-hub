# 项目说明（Project Description）

## 1. 背景与目标

本项目的目标用户是**人工智能专业大一学生**，需要在暑假寻找实习（方向偏 AI / Python）。
在面试中，企业更看重"是否真的动手做过东西、是否理解岗位技术方向、是否有工程规范意识"，
而非堆砌理论。

因此，本项目以一个**贴近真实业务的知识库问答（RAG）系统**为载体，覆盖五个目标岗位方向：

1. **AI 应用开发**：把模型能力包装成用户能用的产品（Web 界面 + 交互设计）。
2. **大模型训练**：展示对微调（LoRA）流水线的理解，而不只是"调 API"。
3. **云运维**：展示把应用容器化、做 CI/CD、加监控的完整闭环。
4. **RAG 开发**：系统核心，展示检索增强生成的完整技术链路。
5. **Python 后端开发**：用 FastAPI 提供稳定、规范的服务接口。

## 2. 功能清单

| 功能 | 说明 | 对应模块 |
| --- | --- | --- |
| 文档管理 | 上传 / 列出 / 删除知识库文档 | `backend` + `rag` |
| 智能问答 | 输入问题，返回带原文出处的答案 | `rag.pipeline` |
| 文档切片 | 长文本按语义/长度切分为 chunk | `rag.chunker` |
| 向量检索 | TF-IDF 向量化 + 余弦相似度召回 | `rag.embedder` / `rag.vector_store` |
| 答案合成 | 抽取式合成（离线可用）+ 可选 LLM | `rag.llm` |
| 对话界面 | 流式/非流式问答体验 | `ai_app` |
| 模型微调 | LoRA 微调脚本与推理 | `llm_training` |
| 容器部署 | 多服务编排 + 反向代理 | `deploy` |

## 3. 使用场景

- **个人学习**：从零理解 RAG 与 LLM 应用的技术栈。
- **面试作品**：展示"能独立做出一个可运行系统"的能力。
- **教学演示**：老师可用来演示 AI 应用从开发到上线的全过程。

## 4. 设计原则

- **可运行优先**：核心模块零依赖可跑，避免"演示十分钟，装环境一小时"。
- **可替换架构**：每个外部依赖（嵌入模型、向量库、LLM）都留好接口，方便讲"生产级升级方案"。
- **工程规范**：分层目录、分层依赖、测试、Docker、CI/CD 一应俱全。
- **文档驱动**：把"为什么这么做"写清楚，体现思考深度。
