# AI 应用模块（Streamlit 前端）

本模块是面向最终用户的**对话式知识库问答界面**，对应目标岗位方向"AI 应用开发"。
它消费后端 API，并把"答案 + 引用来源 + 检索片段"清晰地呈现给用户。

## 特点

- 默认调用后端 API（`http://localhost:8000`），体现前后端分离与联调。
- **自动回退**：若后端未启动，自动切换到本地 RAG 流水线，保证界面本身可独立演示。
- 展示引用来源与检索片段，体现"答案可溯源、降低幻觉"的产品设计思路。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

打开终端给出的本地地址（默认 http://localhost:8501）即可使用。
左侧可修改后端 API 地址；未启动后端时会显示"本地 RAG 回退"。

## 面试可讲的点

- 为什么前后端分离、前端如何与后端约定数据结构（JSON）。
- 用户体验细节：加载态（spinner）、错误处理（回退）、结果可解释（引用/片段）。
- 原型工具选型：Streamlit 适合快速验证；生产可换 React/Vue + 正规前端工程。
